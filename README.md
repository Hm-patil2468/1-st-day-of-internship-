Part G: Reconnaissance Report (Conclusion)
Passive reconnaissance is the first phase of ethical hacking. In this task, publicly available information about the target website was collected without interacting with or exploiting the system. WHOIS lookup provided domain registration details, DNS enumeration revealed important DNS records, and technology identification showed the web server, programming language, CMS, and CDN used by the website. HTTP security headers indicated how the website protects against common attacks such as XSS, clickjacking, and MIME sniffing. The robots.txt and sitemap files provided insight into the website structure and search engine indexing rules. Overall, this activity demonstrated how valuable information can be gathered using only publicly accessible resources while following ethical and legal guidelines.
